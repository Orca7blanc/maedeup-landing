# 책과콩나무 후기 전체 캡처

후기 카드의 발췌 이미지는 유지하고, 이미지와 출처 링크를 모두 전체 후기 페이지로 연결한다. 전체 페이지는 네 장의 원본 JPG를 SVG 조각으로 이어 표시한다. JPG 바이트와 글자는 수정하지 않는다. 화면에는 반복되는 앱 고정바, 카페 광고와 게시판 공지를 제외한다. 제목, 작성자, 작성일, 도서 제공 표시, 책 사진과 후기 본문을 보존한다.

생성: `node scripts/build-full-review-captures.mjs`. 원본 크기는 모두 1080×2187이며 클립 좌표는 생성기에 기록했다. 끝 Y는 포함하지 않는다.

## 정합 검증

- 나난 3권: 01→02 이동 1880px, 02→03 1795px, 03→04 1805px. 겹친 픽셀의 평균 절대 오차는 각각 0.129, 0.122, 0.130/255. 첫 문장부터 마지막 “게 만들어 버리지 않았은가.”까지 보존. 합본 1080×5163.
- 까망새 1권: 02→03 이동 1790px, 03→04 1802px. 겹친 픽셀의 평균 절대 오차는 각각 0.024, 0.017/255. “p.34” 및 “이 사업에는…” 경계를 흰 줄에서 연결. 합본 1080×6585.
- 까망새 01과 02는 서로 다른 책 사진이다. 두 사진은 캡처된 범위만 순서대로 보존하며 앱바에 가려진 사진 부분을 만들어 넣지 않는다. 본문 첫 문단부터 마지막 추천 결론까지의 텍스트 연결에는 누락이 없다.

원본 구분: 나난 03과 까망새 04는 기존 `*-source-20261024.jpg`를 재사용하고, 나머지 원본은 `*-pageN-20261025.jpg`로 보존한다.
